# 5G 设备运维报告生成

## 执行流程

1. **采集数据** — 调用 MCP 工具查询设备详情和当前告警列表
2. **分析根因** — 根据告警类型和级别判断严重程度，给出初步根因分析
3. **生成报告** — 按标准格式输出，写入 `/workspace/report_${device_id}_${date}.md`

## 报告模板

```markdown
# 5G 设备运维诊断报告

| 项目 | 内容 |
|------|------|
| 设备编号 | {device_id} |
| 厂商型号 | {vendor} {model} |
| 站点位置 | {site} |
| 诊断时间 | {timestamp} |

## 告警列表
{告警详细列出}

## 根因分析
{基于告警的推理分析，不超过 3 段}

## 处理建议
1. {建议1}
2. {建议2}
3. {建议3}
```

## 注意事项

- P0 级告警（基站退服）必须标注"紧急"
- 处理建议必须包含短期应急措施和长期修复方案
- 报告文件名格式：report_DEV-XXXX_YYYYMMDD.md
