# 5G 基站常见故障排查

## 光模块故障
收光功率低于-28dBm视为异常，低于-30dBm为严重故障。
常见原因：光纤接头脏污、对端发光模块老化、光纤弯曲半径过小。

排查步骤：
1. 清洁光纤接头和光模块端面
2. 检查对端光模块发光功率
3. 测量光纤链路损耗（OTDR）
4. 更换光模块测试
5. 检查光纤弯曲半径是否过小

## 端口Down
1. 检查物理链路：确认网线/光纤连接正常
2. 查看端口错误计数：display interface 查看 CRC 错误
3. 检查对端设备状态：是否掉电或端口关闭
4. 尝试 shutdown/undo shutdown 重置端口
5. 更换光模块或网线测试

## AAU 发射功率异常
发射功率超过 40W（46dBm）视为异常。
检查项：驻波比、温度、供电电压。
