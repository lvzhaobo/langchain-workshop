📌 质量评测回答一个问题：“AI 答得好不好，怎么用数据说话？”（实验 2.10）。真实项目三板斧： ① LLM-as-Judge — 用另一个 LLM 当“质检员”给每条真实对话打分（离线跑，不拖慢在线对话）； ② Golden Set 回归 — 固定题集当“考卷”，改提示词/换模型后重考一遍，防退化； ③ 人工抽检 — 对话记录里的 👍👎，用来校准机器打分是否靠谱。

📐 评分维度（Judge Prompt 里就这三条）

维度质检员在问什么1 分5 分
faithful 忠实度回答的每句话在知识库里有依据吗？编造内容句句有据
relevant 相关性答的是用户问的这个问题吗？答非所问正中要害
citation 引用规范是否正确标注了分块编号（如 C04）？乱引/不引编号准确
工作流程：读 runs.jsonl 里「有回答且未评分」的记录 → 把 问题+检索片段+回答 交给 DeepSeek（temperature=0）→ 返回 JSON 三维打分回写。上线后每天定时跑一批，就是“自动质检流水线”。曾真实逮到过一个 bug：回答引用 C01 但实际命中 C04，Judge 打了 1 分 → 修好了 Prompt 拼接。
