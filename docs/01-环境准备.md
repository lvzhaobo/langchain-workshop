# 环境准备（macOS）

> 目标：**5 分钟内**能跑出 `./run.sh lab-01` 的结果。装不上的时候看这里，不要自己发明流程。

## 你需要什么

| 东西 | 是否必须 | 检查命令 |
|---|---|---|
| macOS | ✅ | — |
| Python 3.11+ | ✅ | `python3 -V` |
| Xcode Command Line Tools | ✅ 编译某些包需要 | `xcode-select -p` |
| uv（可选，但强烈推荐） | ⬜ | `uv --version` |

**不需要 make，也不需要 Docker。** 全部流程就是 6 个 `.sh` 脚本。

## 标准流程

```bash
cd langchain-workshop
./setup.sh          # 建 venv + 装依赖
./doctor.sh         # 看到 langgraph 1.2.7 就对了
./run.sh lab-01     # 输出 {'n': 1, 'trace': ['think-1']}
```

**不要手动 `source .venv/bin/activate`**——所有脚本都会自己用 `.venv/bin/python`。
（只有想进交互式 shell 时才需要 activate。）

## 6 个脚本各干什么

| 脚本 | 作用 |
|---|---|
| `./setup.sh` | 建 `.venv`（Python 3.11）+ 装 `requirements.txt`。跑一次 |
| `./doctor.sh` | 打印 python 路径、Python 版本、三个依赖版本、uv 状态 |
| `./run.sh lab-01` | 跑某个 lab 的 `main.py`（你的代码） |
| `./check.sh lab-01` | 验收你的代码；加 `-s` 验参考答案 |
| `./verify.sh` | 一次性验收全部 lab 的参考答案 |
| `./clean.sh` | 删 `.venv` 和 `__pycache__` |

lab 名支持三种写法：`lab-01` / `01` / `lab-01-hello-graph`。

## 没装 uv 也能跑

`setup.sh` 会自动降级：

```bash
if command -v uv >/dev/null 2>&1; then uv venv --python 3.11 .venv
else                                 python3 -m venv .venv; fi
```

区别只是**建 venv 更慢**，以及 Python 版本跟系统一致（不一定是 3.11）。能跑就不用装。

## 常见问题

### 1. `./setup.sh: Permission denied`

```bash
chmod +x *.sh scripts/*.sh
```

### 2. `./setup.sh` 卡在 "Installing Python 3.11"

`uv` 在下载 Python。国内网络可能要 1–3 分钟，正常。急着跳过就改用系统 Python：

```bash
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
```

### 3. `pip install` 特别慢或超时

换国内镜像（临时用，别写进配置）：

```bash
uv pip install --python .venv/bin/python -r requirements.txt \
  --index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. `xcode-select: error: command line tools are required`

```bash
xcode-select --install
```

装完再跑 `./setup.sh`。

### 5. 报 `ModuleNotFoundError: langgraph`

九成是**用了系统 python 而不是 venv 的 python**。确认：

```bash
./doctor.sh          # 第一行应该是 .venv/bin/python
```

### 6. `./run.sh lab-01` 说"找不到 lab-01"

```bash
./run.sh             # 不带参数 → 列出全部可用 lab
```

### 7. 版本对不上，报了一堆看不懂的错

LangChain 1.x 和 0.x **不兼容**，LangGraph 1.x 和 0.2.x 也有 breaking change。
网上 2024–2025 年的教程基本都是旧版写的。

```bash
./doctor.sh          # 必须是 langgraph 1.2.7 / langchain-core 1.5.1
```

对不上就 `./clean.sh && ./setup.sh` 重来。

- [ ] `./verify.sh` 三个 lab 全 ✅
- [ ] `./run.sh lab-01` 输出 `{'n': 1, 'trace': ['think-1']}`
