# 模型配置：换 provider 只改一个变量

> **`labs/01–03` 完全不需要 Key**，可以跳过本文。
> `labs/04–26` 需要一个对话模型；RAG 相关的还需要一个 Embedding 模型。

## 为什么能随便换

所有 lab 都走 **OpenAI 兼容协议**，没有直接依赖任何厂商 SDK：

```python
ChatOpenAI(
    model=os.getenv("AGENT_MODEL"),
    api_key=os.getenv("AGENT_API_KEY"),
    base_url=os.getenv("AGENT_API_BASE", "https://api.deepseek.com/v1"),
)
```

`FAISS` 走的是 `langchain_community.vectorstores`，也没有厂商绑定。

**所以换模型 = 改 `AGENT_API_BASE` + `AGENT_MODEL` 两个环境变量，不动代码。**

## 两组变量

| 组 | 用途 | 用在哪 | 默认 |
|---|---|---|---|
| `AGENT_API_KEY`<br>`AGENT_API_BASE`<br>`AGENT_MODEL` | 对话 | 16 处 | DeepSeek |
| `DASHSCOPE_API_KEY`<br>`DASHSCOPE_BASE_URL`<br>`DASHSCOPE_EMBEDDING_MODEL` | Embedding | 8 处（RAG） | 阿里云百炼兼容模式 |

## 常见 provider 配置

### DeepSeek（默认，最便宜）

```bash
AGENT_API_KEY=sk-xxx
AGENT_API_BASE=https://api.deepseek.com/v1
AGENT_MODEL=deepseek-chat
```

### OpenAI

```bash
AGENT_API_KEY=sk-xxx
AGENT_API_BASE=https://api.openai.com/v1
AGENT_MODEL=gpt-4o-mini

DASHSCOPE_API_KEY=sk-xxx          # 同一个 key
DASHSCOPE_BASE_URL=https://api.openai.com/v1
DASHSCOPE_EMBEDDING_MODEL=text-embedding-3-small
```

### 通义千问（阿里云百炼）

```bash
AGENT_API_KEY=sk-xxx
AGENT_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
AGENT_MODEL=qwen-plus
```

### 本地 Ollama（零成本，不需要任何 Key）

```bash
# 先跑：ollama pull qwen2.5:7b && ollama pull nomic-embed-text
AGENT_API_KEY=ollama
AGENT_API_BASE=http://localhost:11434/v1
AGENT_MODEL=qwen2.5:7b

DASHSCOPE_API_KEY=ollama
DASHSCOPE_BASE_URL=http://localhost:11434/v1
DASHSCOPE_EMBEDDING_MODEL=nomic-embed-text
```

### 本地 vLLM

```bash
AGENT_API_KEY=EMPTY
AGENT_API_BASE=http://localhost:8000/v1
AGENT_MODEL=Qwen/Qwen2.5-7B-Instruct
```

## 常见的报错

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `401 Authentication Fails, Your api key: ****_KEY is invalid` | 没填 `.env`，用了占位符 `REPLACE_ME_NO_KEY` | `cp .env.example .env` 并填 `AGENT_API_KEY` |
| `Missing credentials` | 变量名写错，或 `.env` 不在运行目录 | 确认 lab 里 `load_dotenv()` 能找到 `.env` |
| `Connection error` | `base_url` 拼错 / 本地服务没起 | 先用 curl 试：`curl $AGENT_API_BASE/models` |
| Embedding 维度不匹配 | 换了 embedding 模型，但本地 `faiss_index/` 是旧模型建的 | 删掉 `faiss_index/` 重新跑建索引那一步 |
| `404 model not found` | `AGENT_MODEL` 名字不对 | 查 provider 文档的模型 ID，别用显示名 |

## 换 Embedding 模型要重建索引

`faiss_index/` 里的向量维度取决于建索引时的 embedding 模型。
换了 embedding（比如从百炼 `text-embedding-v3` 换到 OpenAI `text-embedding-3-small`），
**必须删掉旧索引重新生成**，否则报维度不匹配。

```bash
rm -rf labs/12-FAISS向量库/faiss_index
cd labs/12-FAISS向量库 && python build_index.py
```
