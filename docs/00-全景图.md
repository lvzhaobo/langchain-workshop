# 全景图

> 培训第一页和最后一页都用这张图。中间所有 lab 都是在拆它的某个零件。

## 一张图

```
                     ┌──────────────────────────────────────┐
   用户提问  ───────▶ │            State（共享状态）          │
                     └──────────────────────────────────────┘
                                    ▲  ▲  ▲
              ┌─────────────────────┘  │  └─────────────────────┐
              │                        │                        │
        ┌───────────┐           ┌───────────┐            ┌───────────┐
        │  模型节点  │──tool──▶ │  工具节点  │──result──▶ │  判断/路由  │
        └───────────┘           └───────────┘            └───────────┘
              │                                                │
              └──────────── 条件边：继续 or 结束 ◀──────────────┘
                                    │
                          ┌─────────▼─────────┐
                          │  Checkpointer 持久化 │  ← thread_id 隔离
                          └───────────────────┘
```

## 三个 lab 分别拆的是哪一块

| 零件 | 在哪个 lab 练 |
|---|---|
| State / Node / 条件边 | **lab-01** |
| 工具节点 + 路由判断 | **lab-02** |
| Checkpointer + thread_id | **lab-03** |

## 讲这一页时要说清的三句话

1. **State 是唯一的真相**。节点不互相调用，只读写 State。
2. **边决定下一步**。普通边是写死的，条件边是函数算出来的——这一条让「循环」成为可能。
3. **Checkpointer 让图可以被暂停和恢复**。没有它，LangGraph 就只是个函数链。
