# Lab 16 · Memory —— 让 Agent 记住对话

> lab 14 的 Agent 每次调用都是独立的新对话——记不住上一轮说了什么、不知道你之前查过哪台设备。本实验给 Agent 加上记忆，对比三种策略：全记、只记最近几轮、自动摘要。

---

## 🎯 实验目标

- 同段 7 轮排障对话，分别用 Buffer / Window / Summary 三种 Memory 策略跑一遍
- 对比 Token 消耗和信息保留率
- 搞清楚"什么时候用哪种记忆"

### 三种策略对比

| 策略 | 原理 | Token 消耗 | 信息保留 |
|------|------|:--:|:--:|
| **Buffer** | 保留全部对话历史 | 线性增长，越长越贵 | 全部保留 |
| **Window** | 只保留最近 K 轮（K=4） | 恒定 | 旧信息丢失 |
| **Summary** | 旧消息自动压缩为摘要 | 比 Buffer 低、比 Window 高 | 记住要点、丢失细节 |

### 模拟场景

```
第1轮：用户说"我负责望京SOHO站点的运维"
第2轮：用户问"这个站点有多少设备？"
第3轮：问另一台设备的状态
第4轮：问一个通用的排障问题
第5轮：问"我们站点最常用的设备型号是什么？"
第6轮：闲聊其他话题
第7轮：问"我们一开始说的是哪个站点？"

Buffer：✅ "望京SOHO"
Window：❌ "不记得了"（Window=4，第1轮已经滚出窗口）
Summary：✅"你提到过望京SOHO站点"
```

### 结果解读

- **Buffer**：信息最全，但 Token 消耗最高。适合短对话。
- **Window**：Token 恒定，但丢旧信息。适合客服场景（只关心最近几轮）。
- **Summary**：最佳性价比。既省 Token 又保留关键信息。

### 接入平台：多轮对话历史

在平台聊天面板加上对话历史——同一 `conversation_id` 的对话中，Agent 能记住上文。

**后端新增 `/chat/conversation` 接口**（在 `server.py` 中追加）：

```python
from collections import defaultdict

conversations = defaultdict(list)  # conversation_id → [(role, content), ...]


@app.route("/chat/conversation", methods=["POST"])
def chat_conversation():
    """多轮对话：同一 conversation_id 内 Agent 能记住上文"""
    data = request.get_json()
    conv_id = data.get("conversation_id", str(uuid.uuid4())[:8])
    user_message = data.get("message", "").strip()

    if not user_message:
        return jsonify({"reply": "请输入问题", "conversation_id": conv_id})

    # 拼接历史消息（最近 10 轮）
    history = conversations[conv_id]
    history_text = "\n".join([
        f"{'用户' if r == 'user' else '助手'}: {c}"
        for r, c in history[-10:]
    ]) if history else ""

    full_message = (
        f"对话历史：\n{history_text}\n\n用户当前问题：{user_message}"
        if history_text else user_message
    )

    reply = _call_agent(full_message)

    # 保存历史
    history.append(("user", user_message))
    history.append(("assistant", reply))
    if len(history) > 40:  # 最多保留 20 轮
        conversations[conv_id] = history[-40:]

    return jsonify({
        "reply": reply,
        "conversation_id": conv_id,
        "history_length": len(history),
    })
```

**前端带上 `conversation_id`**：
