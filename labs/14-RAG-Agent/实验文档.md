### 第一步：新增 `search_kb` 工具

在 lab 05 的 `agent_langchain.py` 基础上，新增一个工具。最终文件命名为 `agent_rag.py`：

```python
# 在原有 query_device、list_devices、get_alarms 三个工具基础上，新增：

from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS

@tool
def search_kb(query: str) -> str:
    """在 5G 基站排障知识库中搜索相关内容。当用户询问故障原因、排查方法、处理流程时，
    优先使用此工具检索知识库。返回 Top 3 最相关的排障文档片段和相似度分数。"""
    embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
    vectorstore = FAISS.load_local(
        "../12-FAISS向量库/faiss_index",
        embeddings,
        allow_dangerous_deserialization=True
    )
    docs = vectorstore.similarity_search_with_relevance_scores(query, k=3)

    if not docs or docs[0][1] < 0.5:
        return "知识库中未找到高度相关内容，建议换个角度描述问题或联系二线专家。"

    result_parts = []
    for doc, score in docs:
        source = doc.metadata.get("source", "未知来源")
        result_parts.append(
            f"[来源: {source}] [相似度: {score:.2f}]\n{doc.page_content}"
        )
    return "\n\n---\n".join(result_parts)
```

### 第二步：创建 RAG Agent

```python
# agent_rag.py 尾部

from langchain.agents import create_react_agent, AgentExecutor
from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate

def create_rag_agent():
    llm = ChatOpenAI(model="deepseek-chat", temperature=0, ...)

    # 现在有 4 个工具了
    tools = [query_device, list_devices, get_alarms, search_kb]

    prompt = ChatPromptTemplate.from_messages([
        ("system", """你是 5G 基站智能排障助手。你可以使用以下工具：

- query_device：查询指定设备详情
- list_devices：获取设备列表
- get_alarms：查询设备告警
- search_kb：检索排障知识库（故障原因、排查步骤、处理流程）

**工作流程**：
1. 先调 query_device/get_alarms 获取设备状态
2. 再调 search_kb 检索相关排障知识
3. 综合设备数据和知识库内容，给出诊断建议

**回答要求**：
- 引用知识库中的具体步骤和命令
- 标注引用的文档来源
- 知识库中没有的内容，如实说明

可用工具：{tools}
工具名称：{tool_names}

Question: 用户的问题
Thought: 我需要做什么
Action: 工具名称
Action Input: 工具参数
Observation: 工具返回的结果
...（可重复 Thought/Action/Observation）
Final Answer: 最终回答"""),
        ("human", "{input}"),
        ("placeholder", "{agent_scratchpad}"),
    ])

    agent = create_react_agent(llm, tools, prompt)
    return AgentExecutor(
        agent=agent, tools=tools, verbose=True,
        max_iterations=10, handle_parsing_errors=True,
    )
```

### 第三步：新增 `/rag/analyze` 接口

在 `server.py` 中新增：

```python
from agent_rag import create_rag_agent
rag_agent = create_rag_agent()

@app.route("/rag/analyze", methods=["POST"])
def rag_analyze():
    """RAG Agent 分析——调设备 API + 搜知识库，综合诊断"""
    data = request.get_json()
    device_id = data.get("device_id", "").strip()

    prompt = (
        f"请分析设备 {device_id} 的状态和告警情况。\n"
        f"先查询设备数据和告警，再检索知识库中相关排障步骤，最后给出综合诊断建议。"
    )
    try:
        result = rag_agent.invoke({"input": prompt})
        return jsonify({"reply": result["output"]})
    except Exception as e:
        return jsonify({"reply": f"Agent 处理失败：{str(e)}"})
```

```javascript
async function analyzeDeviceRAG(deviceId) {
  const btn = document.getElementById('btnRAGAnalyze');
  const resultDiv = document.getElementById('ragResult');
  btn.disabled = true;
  btn.textContent = '分析中…';
  resultDiv.style.display = 'none';

  const resp = await fetch('/rag/analyze', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ device_id: deviceId })
  });
  const data = await resp.json();
  resultDiv.textContent = data.reply;
  resultDiv.style.display = 'block';
  btn.disabled = false;
  btn.textContent = '📚 RAG 分析';
}
```

### 第五步：三个按钮对比

同一台告警设备（如 DEV-0001），依次点三个按钮：

| 按钮 | Agent 能力 | 回答特点 |
|------|-----------|---------|
| 🤖 扣子/Dify 分析 | 低代码 Agent | 平台把设备数据拼进 Prompt 发给 Agent |
| 🦜 LangChain 分析 | 代码级 + 调设备 API | Agent 自己调 `query_device` 拿数据 |
| 📚 RAG 分析 | 代码级 + 调设备 API + 搜知识库 | 比 LangChain 多了知识库检索，回答有文档依据 |

观察三个回答：
- 扣子/Dify：有没有用到设备实际数据？
- LangChain：推理过程（终端 verbose 输出）走了几步？
- RAG：引用了知识库的哪篇文档？步骤具体到什么程度？
