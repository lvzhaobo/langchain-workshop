## 📦 标准路径

### 第一步：拿到 Embedding 向量

从 lab 12 的 FAISS 索引中取出向量和对应文本：

```python
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_community.document_loaders import DirectoryLoader, TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 加载 lab 12 的索引（或重新向量化同一批文档）
vectorstore = FAISS.load_local(
    "../12-FAISS向量库/faiss_index",
    embeddings,
    allow_dangerous_deserialization=True
)

# 取一个 Query 的向量
query = "AAU5613 SCTP 链路中断怎么处理"
query_vec = embeddings.embed_query(query)  # 1536 维浮点数组

# 取 FAISS 索引中所有文档的向量
# FAISS 索引不直接暴露向量列表，这里用另一种方式：
# 重新加载文档，逐条向量化
loader = DirectoryLoader("../12-FAISS向量库/data/", glob="**/*.md", loader_cls=TextLoader)
docs = loader.load()
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)

doc_vectors = [embeddings.embed_query(c.page_content) for c in chunks]
print(f"Query 向量维度: {len(query_vec)}")
print(f"文档向量数量: {len(doc_vectors)}")
```

### 第二步：手写余弦相似度

```python
import numpy as np

def cosine_similarity(vec_a, vec_b):
    """
    计算两个向量的余弦相似度。

    公式：cos(θ) = (A · B) / (||A|| × ||B||)
    即：点积除以模的乘积

    结果范围：-1 到 1
    - 1：方向完全一致
    - 0：正交（无关）
    - -1：方向完全相反
    """
    a = np.array(vec_a)
    b = np.array(vec_b)

    dot_product = np.dot(a, b)          # 点积
    norm_a = np.linalg.norm(a)           # A 的模（长度）
    norm_b = np.linalg.norm(b)           # B 的模（长度）

    if norm_a == 0 or norm_b == 0:
        return 0.0  # 零向量无方向

    return float(dot_product / (norm_a * norm_b))


# 验证：和自己算，应该约等于 1
self_sim = cosine_similarity(query_vec, query_vec)
print(f"自己和自己的余弦相似度: {self_sim:.6f}（预期接近 1.0）")

# 验证：和随机向量算，应该接近 0
random_vec = np.random.randn(len(query_vec)).tolist()
rand_sim = cosine_similarity(query_vec, random_vec)
print(f"和随机向量的余弦相似度: {rand_sim:.6f}（预期接近 0.0）")
```

### 第三步：对所有文档向量计算相似度，排序

```python
# 计算 query 和每个文档段的相似度
results = []
for i, doc_vec in enumerate(doc_vectors):
    sim = cosine_similarity(query_vec, doc_vec)
    results.append({"index": i, "similarity": sim, "content": chunks[i].page_content[:100]})

# 按相似度降序排列
results.sort(key=lambda x: x["similarity"], reverse=True)

# 展示 Top 5
print(f"\nQuery: {query}\n")
for r in results[:5]:
    print(f"[{r['similarity']:.4f}] {r['content']}...")
```

### 1. 对比三种距离度量

除了余弦相似度，还有欧氏距离（L2）和点积。实现这三个，对比同一组向量的排序结果是否一致：

```python
def euclidean_distance(a, b):
    return np.linalg.norm(np.array(a) - np.array(b))

def dot_product_score(a, b):
    return np.dot(np.array(a), np.array(b))
```

### 2. 为什么用余弦而不是欧氏距离？

对文本 Embedding 来说，方向比绝对位置重要——"两个文本意思相近"等价于"向量方向接近"，不等价于"两个点距离近"。用一个反例验证：同一段话，用不同语气写两次（正式 vs 口语），Embedding 向量长度不同但方向接近——余弦相似度高、欧氏距离大。
