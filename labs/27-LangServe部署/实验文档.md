# Lab 27 · LangServe 把图变成 HTTP API

> 前面 26 个 lab 都是"在终端里跑出结果"。这一个解决：**写完了怎么给别人用。**

## 一句话

`add_routes(app, graph, path="/diagnose")` —— 一行代码，把图变成 5 个 HTTP 端点。

## 为什么不用手写 FastAPI 路由

手写的话，每个能力都要自己来：

| 能力 | 手写 | LangServe |
|---|---|---|
| 单条调用 | 定义 Pydantic 请求/响应模型 + 路由 + 序列化 | `/invoke` 自动生成 |
| 批量 | 再写一个路由 + 循环 | `/batch` 自动生成 |
| 流式 | SSE 编码、事件格式、断线处理 | `/stream` 自动生成 |
| 调试界面 | 自己写前端 | `/playground` 自带 |
| API 文档 | 手写 OpenAPI | `/openapi.json` 自动生成 |

**关键点**：这些端点不是"能跑就行"，它们共享同一套输入输出 schema（从图的 State 推导）。

## 跑一遍

```bash
./run.sh 27
```

会依次演示五件事：端点清单 → 单条 → 批量 → 流式 → playground。

## 怎么打开 playground

**关键：`./run.sh 27` 跑完会关掉服务**，它只是自测。要常驻，另开一个终端：

```bash
./run.sh 27 --serve
```

看到这段就说明起来了：

```
================================================================
  LangServe 常驻服务
================================================================
  Playground : http://127.0.0.1:8123/diagnose/playground/
  OpenAPI    : http://127.0.0.1:8123/openapi.json
  invoke     : POST http://127.0.0.1:8123/diagnose/invoke
  Ctrl+C 停止
```

然后浏览器打开 **`http://127.0.0.1:8123/diagnose/playground/`**

### 两个容易踩的点

| 现象 | 原因 | 解 |
|---|---|---|
| 打不开 / 连接被拒 | `./run.sh 27` 已经跑完退出了 | 用 `--serve` 常驻 |
| 能连但 307 跳转 | URL **少了结尾斜杠** | 补上 `/`：`.../playground/` |

## 三个必须知道的细节

### ① State 里只有 `device_id` 是调用方要传的

```python
class State(TypedDict):
    device_id: str                                        # 必填
    device_info: NotRequired[str]                         # 图内部产生
    diagnosis: NotRequired[str]                           # 图内部产生
    trace: NotRequired[Annotated[list[str], reducer]]     # 图内部产生
```

**不标 `NotRequired` 会 422**。因为 LangServe 从 State 推导请求体，不标就全是必填字段，
调用方得把 `diagnosis` 也传上来——但它明明是图算出来的。

这个坑第一次踩必中，报错只有一句 `422 Unprocessable Entity`，没有细节。

### ② `typing.TypedDict` 在 Python < 3.12 会炸

```
PydanticUserError: Please use `typing_extensions.TypedDict`
```

必须 `from typing_extensions import TypedDict, NotRequired`。

### ③ `/stream` 推的是节点级事件

图里有 `detect` 和 `diagnose` 两个节点，流里就至少两个事件，加上结束标记一共 3 个。
**不是"逐字"流**——要逐字得在节点内部用 `astream_events`。

## 打卡内容

1. `/invoke` 返回的状态码和 `trace` 字段
2. `/batch` 一次返回几条
3. `/stream` 收到几个 SSE 事件
4. 截图 playground 页面

## 常见问题

| 现象 | 原因 | 解 |
|---|---|---|
| `422 Unprocessable Entity` | State 字段没标 `NotRequired` | 见上面 ① |
| `PydanticUserError: use typing_extensions.TypedDict` | Python < 3.12 | 换 import |
| `add_routes` 报 not a Runnable | 传了未 compile 的 StateGraph | 传 `workflow.compile()` 的返回值 |
| 端口被占用 | 8123 有别的服务 | 脚本会自动找空闲端口 |

## 和下一节的关系

LangServe 解决了"**能被调用**"，但没解决"**调用得怎么样**"——
慢在哪、哪一步花了多少钱、用户问了什么答歪了，它都看不到。
那是 [Lab 28 · LangSmith 追踪](../28-LangSmith追踪/实验文档.md) 的事。
