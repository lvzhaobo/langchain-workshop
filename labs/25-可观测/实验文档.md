# Lab 25 · 可观测 Trace — 多 Agent 流水线每一步的耗时与 Token

> 27-28 的多 Agent 流水线跑起来了，但你不知道哪个 Agent 最慢、哪个工具调用出错、整个链路消耗了多少 Token。本实验给 Agent 加上 Trace 能力——每次调用生成一条完整链路，每个子步骤独立记录耗时和 Token。

---

## 🎯 实验目标

- 理解 Trace（链路）和 Span（子步骤）的概念
- 实现本地 Trace 收集器——不依赖外部服务（LangFuse/LangSmith 需注册，本地版零门槛）
- 多 Agent 流水线的每一步耗时可视化（控制台 ASCII 柱状图）
- 对比不同复杂度任务的 Trace 差异

---

## 📦 标准路径

### 第一步：理解 Trace 模型

```
一条 Trace（一次用户请求）
├── Span: detector         150ms  ████████░░░░░░░░░░░░
│   ├── Span: query_device  45ms  ██░░░░░░░░░░░░░░░░░░
│   └── Span: llm          105ms  █████░░░░░░░░░░░░░░░
├── Span: diagnoser        350ms  ██████████████████░░
│   ├── Span: search_kb     80ms  ████░░░░░░░░░░░░░░░░
│   └── Span: llm          270ms  ██████████████░░░░░░
├── Span: decider          150ms  ████████░░░░░░░░░░░░
└── Span: executor         100ms  █████░░░░░░░░░░░░░░░
─────────────────────────────────
总耗时: 750ms | 总 Token: 650
```

### 第二步：LocalTracer 收集器

```python
from trace_demo import LocalTracer

tracer = LocalTracer()

# 开始一条 Trace
tracer.start_trace("排障流水线-DEV-0001", {"device_id": "DEV-0001"})

# 每个子步骤：start_span → 执行业务逻辑 → end_span
tracer.start_span("detector", "agent")
# ... 业务逻辑 ...
tracer.end_span(output={"alarms_found": 2}, tokens=150)

tracer.start_span("search_kb", "tool")
# ... 知识库检索 ...
tracer.end_span(output={"hits": 3}, tokens=80)

# 结束 Trace
trace = tracer.end_trace()
```

### 第三步：可视化报告

```bash
python main.py
```

输出 ASCII 柱状图——一眼看出哪个 Span 最耗时。

### 第四步：对比不同任务

同一台设备的不同分析方式，Traces 有多大差异：

| 任务 | Span 数 | 耗时 | Token | 最慢 Span |
|------|:--:|:--:|:--:|------|
| 简单查设备 | 1 | ~300ms | ~150 | detector |
| 标准排障 | 3 | ~750ms | ~650 | search_kb |
| 复杂诊断 | 5+ | ~1.5s | ~1200 | llm（多次调用） |

### 第五步：生产环境选型

本地 `LocalTracer` 适合开发调试。生产环境推荐 LangFuse（开源、自部署、有 Dashboard）：

```python
# pip install langfuse
from langfuse.langchain import CallbackHandler

callback = CallbackHandler(
    public_key="pk-...",
    secret_key="sk-...",
    host="https://cloud.langfuse.com"  # 或用自部署地址
)

agent.invoke({"input": "..."}, config={"callbacks": [callback]})
# → 自动上报到 LangFuse Dashboard，无需手写 Trace 代码
```
