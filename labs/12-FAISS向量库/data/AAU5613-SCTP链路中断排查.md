# AAU5613 SCTP 链路中断排查

## 适用设备
华为 AAU5613、AAU5639

## 故障现象
- 基站退服告警触发
- SCTP 链路状态显示为 DOWN
- 相邻基站切换成功率下降
- 用户投诉该区域信号中断

## 排查步骤

### 步骤一：检查 SCTP 端点配置
执行命令 `display sctp association`，确认链路状态。
- 正常状态：ESTABLISHED
- 异常状态：CLOSED / INIT / COOKIE_WAIT
- 若状态异常，检查本端和对端的 IP 地址、端口号配置是否一致

### 步骤二：检查底层传输链路
执行命令 `display ip interface brief`，确认本端 IP 地址配置正确、接口状态为 UP。
- 若接口状态 DOWN，检查光纤连接和光模块
- 执行 `ping 对端IP` 验证网络可达性

### 步骤三：检查光模块光功率
执行命令 `display transceiver interface X` 查看光模块信息。
- 发射功率（TX）正常范围：-2 dBm ~ 3 dBm
- 接收功率（RX）正常范围：-11 dBm ~ -1 dBm
- 光功率异常时，先清洁光纤端面，若仍异常则更换光模块

### 步骤四：检查 SCTP 链路拥塞
执行命令 `display sctp statistics`，查看重传次数和拥塞窗口。
- 重传率 > 5% 表明链路质量差或带宽不足
- 建议扩容传输带宽或启用负载分担

## 修复验证
- SCTP 链路状态恢复 ESTABLISHED
- 基站退服告警自动恢复
- 相邻基站切换成功率恢复正常（> 99.5%）

## 常见误判
- 误判为 AAU 硬件故障——本故障 80% 为传输侧或配置问题，应先排查链路和配置
- 忽略高峰时段拥塞——19:00-22:00 高流量可能导致临时性链路中断
