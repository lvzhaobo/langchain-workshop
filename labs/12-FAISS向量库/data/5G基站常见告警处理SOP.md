# 5G 基站常见告警处理 SOP

## 告警类型与处理标准

### 1. 传输中断告警
| 项目 | 内容 |
|------|------|
| 可能原因 | 光缆中断、光模块故障、传输设备故障、配置错误 |
| 自动诊断 | 检查 SCTP 链路状态、ping 对端 IP、查传输设备告警 |
| 手动排查 | 查看 OTDR、检查光纤端面、更换光模块 |
| 升级条件 | 30 分钟内未恢复 → 升级为 P0 工单 |

### 2. 性能劣化告警
| 项目 | 内容 |
|------|------|
| 可能原因 | 小区干扰、用户数超限、天线方位角偏移、AAU 温度过高 |
| 自动诊断 | 检查 KPI（接入成功率、掉线率、吞吐量）、查看干扰底噪 |
| 手动排查 | 调整天线倾角、开启负载均衡、检查 AAU 散热 |
| 升级条件 | 持续劣化 2 小时以上且影响用户体验 → 升级为 P2 工单 |

### 3. 硬件故障告警
| 项目 | 内容 |
|------|------|
| 可能原因 | AAU/BBU 模块故障、电源模块故障、风扇故障、GPS 失锁 |
| 自动诊断 | 查询单板状态、电源输出、温度传感器、GPS 信号强度 |
| 手动排查 | 现场更换故障模块、检查供电线路、更换 GPS 天线 |
| 升级条件 | 涉及 AAU 更换 → 需审批工单，安排维护窗口 |

### 4. 配置错误告警
| 项目 | 内容 |
|------|------|
| 可能原因 | 邻区配置错误、PCI 冲突、功率参数异常、切换参数不当 |
| 自动诊断 | 对比相邻基站配置、检查近期变更记录 |
| 手动排查 | 回滚配置到上一个正常版本、重新下发正确配置 |
| 升级条件 | 配置错误导致大面积影响 → 立即回滚，事后复盘 |

## 告警升级路径
```
P3 提醒 → 自动记录，24 小时内处理
P2 一般 → 通知运维组，4 小时内处理
P1 严重 → 通知值班经理，1 小时内处理
P0 紧急 → 立即通知运维总监，30 分钟内响应
```

## 处理完成标准
- 告警已清除，持续 15 分钟未复现
- 关联 KPI 恢复正常（接入成功率 > 99%、掉线率 < 0.5%）
- 工单中记录根因和处理过程
