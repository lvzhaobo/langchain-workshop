- 验证检索效果——输入故障描述，能否搜到相关排障步骤

## 📦 标准路径

### 第一步：安装 FAISS

```bash
pip install faiss-cpu langchain-openai langchain-community
```

> 注：也可选 Chroma（`pip install chromadb`），元数据过滤更强。本实验以 FAISS 为例。

### 第二步：准备知识文档

本目录的 `data/` 下提供了 3 篇 5G 基站排障文档作为示例。后续 lab 14 会把这些文档真正用起来。

```
data/
├── AAU5613-SCTP链路中断排查.md      # 具体型号的排障手册
├── 基站退服故障排查手册.md           # 通用退服排查流程
└── 5G基站常见告警处理SOP.md         # 标准作业程序
```

### 第三步：文档加载与分割

```python
from langchain_community.document_loaders import TextLoader, DirectoryLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter

# 加载 data/ 下所有 .md 文档
loader = DirectoryLoader("./data/", glob="**/*.md", loader_cls=TextLoader)
documents = loader.load()
print(f"加载了 {len(documents)} 篇文档")

# 分割——每段 500 字符，重叠 50 字符
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=50,
    separators=["\n## ", "\n### ", "\n", "。"]
)
chunks = splitter.split_documents(documents)
print(f"分割为 {len(chunks)} 个文本段")
```

### 第四步：Embedding 向量化 + 存入 FAISS

```python
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS

# 向量化——每条文本变成一串数字（向量）
embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small",
    api_key="你的 API Key"
)

# 写入 FAISS 索引
vectorstore = FAISS.from_documents(chunks, embeddings)

# 持久化到磁盘（下次启动不用重新向量化）
vectorstore.save_local("./faiss_index")
print("FAISS 索引已保存")
```

### 第五步：语义检索测试

```python
# 加载已保存的索引
vectorstore = FAISS.load_local(
    "./faiss_index",
    embeddings,
    allow_dangerous_deserialization=True  # 仅本地可信文件使用
)

# 测试检索
test_queries = [
    "AAU5613 SCTP 链路中断怎么处理",
    "基站退服 P0 告警排查流程",
    "光模块光功率异常怎么检查",
]

for query in test_queries:
    print(f"\n{'='*50}")
    print(f"🔍 用户问：{query}")

    # 检索 Top 3 最相关文本段
    docs = vectorstore.similarity_search_with_relevance_scores(query, k=3)

    for doc, score in docs:
        # 截取前 150 字符展示
        preview = doc.page_content[:150].replace("\n", " ")
        print(f"  📄 [相似度 {score:.3f}] {preview}...")
```

### 第六步：有 RAG vs 无 RAG 对比

同一个问题，对比两种回答：

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="deepseek-chat", temperature=0, ...)

question = "AAU5613 设备退服了，SCTP 链路中断，怎么一步步排查？"

# 无 RAG：直接问 LLM
no_rag_answer = llm.invoke(question)
print("=== 无 RAG ===")
print(no_rag_answer.content[:300])

# 有 RAG：先检索，再带着文档问 LLM
docs = vectorstore.similarity_search(question, k=3)
context = "\n\n".join([d.page_content for d in docs])
rag_prompt = f"请根据以下排障文档回答问题。如果文档中没有相关信息，请如实说明。\n\n文档：\n{context}\n\n问题：{question}"
rag_answer = llm.invoke(rag_prompt)
print("\n=== 有 RAG ===")
print(rag_answer.content[:300])
```

观察差异：
- 无 RAG：Agent 凭 LLM 训练数据回答，可能笼统、可能遗漏关键步骤
- 有 RAG：Agent 引用了排障手册的具体步骤，可溯源

## ⚠️ 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| `faiss-cpu` 安装失败 | 缺少编译工具 | `pip install faiss-cpu` 有预编译 wheel，Windows/Mac 一般直接过 |
| 检索结果相似度都很低 | 文档分割太小或 query 用词不匹配 | 调大 chunk_size，或改写 query 更接近文档原话 |
| 检索返回三段的相似度都差不多 | 文档内容重复或分割时 overlap 太大 | 减小 overlap，去重同类文档 |
| `allow_dangerous_deserialization` 警告 | FAISS 安全提示 | 仅在你自己的文件上使用，不改代码即可 |
