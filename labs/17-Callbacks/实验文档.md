## 📦 标准路径

### 第一步：理解 Callback 机制

LangChain 的 Callback 是一个观察者——它在 Agent 执行的各个阶段"插一脚"：

```
Agent 开始 ──→ on_agent_start
LLM 开始生成 ──→ on_llm_start     ← 记录开始时间
LLM 生成完成 ──→ on_llm_end       ← 拿到 Token 用量和结束时间
工具开始调用 ──→ on_tool_start
工具调用完成 ──→ on_tool_end
Agent 结束 ──→ on_agent_finish    ← 汇总所有指标
```

### 第二步：编写自定义 Callback Handler

```python
# callbacks_demo.py
import time
from typing import Any, Dict, List
from langchain.callbacks.base import BaseCallbackHandler
from langchain_openai import ChatOpenAI
from langchain.agents import tool, create_react_agent, AgentExecutor
from langchain.prompts import ChatPromptTemplate


class MetricsCallback(BaseCallbackHandler):
    """自定义回调——记录每次 Agent 调用的指标"""

    def __init__(self):
        self.reset()

    def reset(self):
        """每次调用前重置指标"""
        self.start_time = None
        self.total_llm_calls = 0
        self.total_tool_calls = 0
        self.total_input_tokens = 0
        self.total_output_tokens = 0
        self.llm_latencies: List[float] = []
        self._current_llm_start = None
        self._pending_input_tokens = 0

    # ── LLM 事件 ──
    def on_llm_start(self, serialized: Dict[str, Any], prompts: List[str], **kwargs):
        self.total_llm_calls += 1
        # 先估算，如果 on_llm_end 拿到了真实值则覆盖
        self._pending_input_tokens = sum(len(p) for p in prompts)
        self._current_llm_start = time.time()

    def on_llm_end(self, response, **kwargs):
        if self._current_llm_start:
            self.llm_latencies.append(time.time() - self._current_llm_start)
            self._current_llm_start = None

        # 从 response 中提取 token 用量
        token_usage = getattr(response, "llm_output", {}) or {}
        usage = token_usage.get("token_usage", {})
        if usage:
            # 有真实值就用真实值（注意：不叠加，覆盖估算值）
            self.total_input_tokens += usage.get("prompt_tokens", self._pending_input_tokens)
            self.total_output_tokens += usage.get("completion_tokens", 0)
        else:
            # 模型没返回 token 数的兜底估算
            self.total_input_tokens += self._pending_input_tokens
            content = getattr(response, "generations", [[]])[0]
            if content and hasattr(content[0], "text"):
                self.total_output_tokens += len(content[0].text)
        self._pending_input_tokens = 0

    # ── 工具事件 ──
    def on_tool_start(self, serialized: Dict[str, Any], input_str: str, **kwargs):
        self.total_tool_calls += 1

    # ── 汇总 ──
    def summary(self) -> Dict[str, Any]:
        total_time = time.time() - self.start_time if self.start_time else 0
        return {
            "总耗时（秒）": round(total_time, 2),
            "LLM 调用次数": self.total_llm_calls,
            "工具调用次数": self.total_tool_calls,
            "输入 Token（估算）": self.total_input_tokens,
            "输出 Token（估算）": self.total_output_tokens,
            "LLM 平均延迟（秒）": round(
                sum(self.llm_latencies) / len(self.llm_latencies), 2
            ) if self.llm_latencies else 0,
        }

    def on_agent_start(self, *args, **kwargs):
        self.start_time = time.time()
```

### 第三步：给 Agent 装上 Callback

```python
# 创建 Agent 时传入 callbacks
cb = MetricsCallback()
llm = ChatOpenAI(model="deepseek-chat", temperature=0, ...)

# 定义工具（复用 lab 14 的 query_device 和 search_kb）
@tool
def query_device(device_id: str) -> str:
    """查询 5G 基站设备详情"""
    import requests
    resp = requests.get(f"http://localhost:8000/devices/{device_id}", timeout=5)
    data = resp.json()
    if not data.get("found"):
        return f"设备 {device_id} 不存在"
    d = data["device"]
    alarms = d.get("alarms", [])
    alarm_info = "\n".join([
        f"  [{a['severity']}] {a['type']}: {a['description']}"
        for a in alarms
    ]) if alarms else "无告警"
    return (
        f"设备 {device_id}：{d['vendor']} {d['model']}，"
        f"站点 {d['site']}，状态 {d['status']}。"
        f"告警（{len(alarms)}条）：\n{alarm_info}"
    )


@tool
def search_kb(query: str) -> str:
    """在排障知识库中搜索相关内容"""
    from langchain_openai import OpenAIEmbeddings
    from langchain_community.vectorstores import FAISS
    embeddings = OpenAIEmbeddings(model="text-embedding-3-small", ...)
    vectorstore = FAISS.load_local(
        "../12-FAISS向量库/faiss_index",
        embeddings,
        allow_dangerous_deserialization=True,
    )
    docs = vectorstore.similarity_search_with_relevance_scores(query, k=3)
    if not docs or docs[0][1] < 0.5:
        return "知识库未找到相关内容"
    return "\n---\n".join([
        f"[{doc.metadata.get('source', '?')}] {doc.page_content[:200]}"
        for doc, score in docs
    ])


tools = [query_device, search_kb]
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是 5G 基站排障助手。… {tools} {tool_names}"),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])
agent = create_react_agent(llm, tools, prompt)
executor = AgentExecutor(
    agent=agent, tools=tools, verbose=True,
    max_iterations=10, handle_parsing_errors=True,
    callbacks=[cb],  # ← 装上 Callback
)
```

### 第四步：实测 5 条查询

```python
# 5 条不同复杂度的查询
TEST_QUERIES = [
    ("简单查设备", "DEV-0001 是什么型号？"),
    ("告警查询", "DEV-0001 有哪些告警？"),
    ("排障+知识库", "DEV-0001 的告警怎么处理？参考知识库给出排查步骤"),
    ("复杂诊断", "帮我分析设备状态异常的原因。先查设备、再搜知识库、再给建议"),
    ("多设备对比", "告警设备有几台？列出最严重的那台的详细信息"),
]

results = []
for label, query in TEST_QUERIES:
    cb.reset()
    result = executor.invoke({"input": query})
    metrics = cb.summary()
    metrics["标签"] = label
    metrics["回答长度"] = len(result["output"])
    results.append(metrics)
    print(f"{label}: {metrics}")

# ── 汇总对比 ──
print(f"\n{'='*70}")
print(f"{'查询标签':<14} {'耗时(s)':>8} {'LLM次数':>8} {'工具次数':>8} {'Token估':>8}")
print(f"{'-'*70}")
for r in results:
    print(
        f"{r['标签']:<14}"
        f"{r['总耗时（秒）']:>8.2f}"
        f"{r['LLM 调用次数']:>8}"
        f"{r['工具调用次数']:>8}"
        f"{r['输入 Token（估算）']:>8}"
    )
```

### 第六步：观察发现

运行 5 条查询后，你应能发现：

- **简单查询**（只调一个工具）：1 次 LLM + 1 次 tool，Token 少
- **排障查询**（调两个工具）：2 次 LLM + 2 次 tool，Token 翻倍
- **复杂诊断**（多次 Thought-Action 循环）：≥3 次 LLM，Token 最高
- **调知识库的查询**比不调的查询贵很多（Embedding + LLM 双开销）

## 🏗️ 进阶挑战

### 1. 按工具/LLM 分项统计

把 Callback 升级——不只汇总，而是分项记录每次工具调用和 LLM 调用的独立指标。Agent 调了 `query_device` 和 `search_kb`，各自耗时多少？

### 2. 设置预算告警

在 Callback 中加一个 `max_tokens` 参数。当累计 Token 超过预算时，Agent 自动终止并返回"超出预算"提示——类似生产环境的 API 用量控制。

### 3. 持久化指标

每次调用后，把指标写入 SQLite 或 JSON 文件。积累 20+ 条调用记录后，分析：哪种问题最贵？哪天 Token 用量最高？

## ⚠️ 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| Token 数量为 0 | DeepSeek 等模型不返回 usage 字段 | 按字符数估算（中文 1 字 ≈ 1 token） |
| Callback 不触发 | AgentExecutor 没传 callbacks 参数 | 确认 `AgentExecutor(..., callbacks=[cb])` |
| 每次调用的 Token 都一样 | 忘记在每次调用前 `cb.reset()` | 确保 `reset()` 在 `invoke()` 之前调用 |
| 工具调用次数为 0 | Agent 没有走工具路径 | 确认问题需要调工具（简单问答 Agent 可能直接回答） |
