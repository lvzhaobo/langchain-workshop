# Lab 19 · RAG 评测 —— 知识库回答到底准不准？

> lab 14 的 RAG Agent 能搜知识库了，但搜出来的东西准不准？返回的是不是最好的那段？本实验建立一套量化评测——用标准数据集测检索质量，用 LLM Judge 评回答质量。同时也给聊天面板加上多轮对话历史，让评测有据可查。

---

## 🎯 实验目标

- 建立 RAG 评测数据集（15+ 条 Q&A），覆盖"能回答""部分能回答""不能回答"三类
- 跑检索质量评测：Recall@K、MRR、Precision
- 用 LLM Judge 评回答质量：完整性、准确性、相关性
- 升级聊天面板：显示对话历史，支持多轮上下文

---

## 🏗️ 评测指标体系

```
RAG 评测分两层：

第一层：检索质量（不看 LLM，只看搜没搜对）
┌─────────────────────────────────────────┐
│ Recall@3   搜到的 Top3 覆盖了多少正确答案  │
│ MRR        正确答案排在第几位？          │
│ Precision  搜到的结果中有几条是相关的？    │
└─────────────────────────────────────────┘

第二层：回答质量（看最终回答好不好）
┌─────────────────────────────────────────┐
│ 完整性    答案是否覆盖了问题的所有方面     │
│ 准确性    答案中的每条陈述是否正确        │
│ 相关性    答案是否紧扣问题               │
│ 可溯源性  答案是否引用了文档             │
└─────────────────────────────────────────┘
```

### 第二步：检索质量评测

```python
# evaluate_rag.py
import json
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS


def load_eval_cases(path="data/eval_cases.json"):
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def load_vectorstore():
    embeddings = OpenAIEmbeddings(
        model="text-embedding-3-small",
        api_key="你的 API Key",
    )
    return FAISS.load_local(
        "../12-FAISS向量库/faiss_index",
        embeddings,
        allow_dangerous_deserialization=True,
    )


def evaluate_retrieval(vectorstore, cases, k=3):
    """评测检索质量：Recall@K、MRR、Precision@K"""
    total_recall = 0
    total_mrr = 0
    total_precision = 0
    detail_results = []

    for case in cases:
        relevant = set(case["relevant_docs"])
        if not relevant:
            # 标记为"不能回答"，检索评测不适用
            detail_results.append({**case, "skip": True})
            continue

        docs = vectorstore.similarity_search_with_relevance_scores(
            case["query"], k=k
        )

        retrieved_sources = set()
        for doc, score in docs:
            source = doc.metadata.get("source", "")
            # 提取文件名
            filename = source.split("/")[-1] if "/" in source else source
            retrieved_sources.add(filename)

        # Recall@K：TopK 中覆盖了多少正确答案文件
        hits = relevant & retrieved_sources
        recall = len(hits) / len(relevant) if relevant else 0

        # Precision@K：TopK 中有几条是相关的
        precision = len(hits) / len(docs) if docs else 0

        # MRR（Mean Reciprocal Rank）：第一个正确答案排在第几位？
        mrr = 0
        for rank, (doc, _) in enumerate(docs, 1):
            source = doc.metadata.get("source", "").split("/")[-1]
            if source in relevant:
                mrr = 1.0 / rank
                break

        total_recall += recall
        total_mrr += mrr
        total_precision += precision

        detail_results.append({
            **case,
            "skip": False,
            "recall": recall,
            "mrr": mrr,
            "precision": precision,
            "retrieved": list(retrieved_sources),
            "top_scores": [round(score, 3) for _, score in docs],
        })

    n = sum(1 for r in detail_results if not r.get("skip"))
    return {
        "Recall@K": round(total_recall / n, 3) if n > 0 else 0,
        "MRR": round(total_mrr / n, 3) if n > 0 else 0,
        "Precision@K": round(total_precision / n, 3) if n > 0 else 0,
        "评测用例数": len(cases),
        "有效用例数": n,
    }, detail_results
```

### 第三步：LLM Judge 评回答质量

```python
def evaluate_answer_quality(query, answer, expected_summary):
    """用 LLM 当裁判，评估回答质量"""
    from langchain_openai import ChatOpenAI

    judge_llm = ChatOpenAI(model="deepseek-chat", temperature=0, ...)

    judge_prompt = f"""你是一个 RAG 回答质量评估专家。请对以下回答进行评分。

用户问题：{query}

助手的回答：
{answer}

预期的回答要点：
{expected_summary}

请从以下四个维度评分（1-5 分）：
1. 完整性：回答是否覆盖了问题的所有方面
2. 准确性：回答中的每条陈述是否正确
3. 相关性：回答是否紧扣问题
4. 可溯源性：回答是否引用了具体文档

只输出 JSON，不要有其他内容：
{{"完整性": 分数, "准确性": 分数, "相关性": 分数, "可溯源性": 分数, "总分": 平均分, "评语": "一句话总结"}}
"""
    response = judge_llm.invoke(judge_prompt)
    try:
        import json
        # 尝试从响应中提取 JSON
        content = response.content
        if "```json" in content:
            content = content.split("```json")[1].split("```")[0]
        elif "```" in content:
            content = content.split("```")[1].split("```")[0]
        return json.loads(content.strip())
    except (json.JSONDecodeError, IndexError):
        return {"error": "无法解析评分", "raw": response.content}
```

### 第四步：跑评测 + 看报告

```python
if __name__ == "__main__":
    cases = load_eval_cases()
    vectorstore = load_vectorstore()

    # ── 检索评测 ──
    retrieval_metrics, details = evaluate_retrieval(vectorstore, cases)
    print("=== 检索质量评测 ===")
    for k, v in retrieval_metrics.items():
        print(f"  {k}: {v}")

    # 逐条详情
    for d in details:
        if d.get("skip"):
            print(f"\n  {d['id']}: {d['query'][:30]}... → 标记为'不能回答'，跳过")
        else:
            icon = "✅" if d["recall"] > 0 else "❌"
            print(f"\n  {icon} {d['id']}: {d['query'][:30]}...")
            print(f"     Recall={d['recall']}, MRR={d['mrr']}, Precision={d['precision']}")
            print(f"     检索到: {d['retrieved']}")
```

## ⚠️ 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| Recall 为 0 | 知识库里没有覆盖这些文档 | 补充知识文档，或调整 expected_docs |
| LLM Judge 解析失败 | LLM 没输出合法 JSON | 在 Prompt 中强调"只输出 JSON"，或加 try/except 兜底 |
| MRR 总是 1.0 | 正确答案总在第 1 位 | 增加困难用例（正确答案在文档中后部） |
| 评测用例数增长慢 | 手工构造效率低 | 用 AI 根据知识库内容自动生成候选 query，人工筛选标注 |
