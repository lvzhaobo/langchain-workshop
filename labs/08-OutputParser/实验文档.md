# Lab 08 · Output Parser —— 让 Agent 输出结构化数据

> lab 05 的 LangChain Agent 返回纯文本，"前端只能当字符串展示"。本实验给 Agent 加上 Output Parser，强制输出结构化 JSON——前端可以按卡片渲染、可以写入数据库、可以被下游系统消费。

---

## 🎯 实验目标

- 理解 Agent 输出为什么需要结构化
- 用 PydanticOutputParser 定义输出 Schema
- 对比"自由文本输出"vs"结构化输出"的差异
- 前端根据结构化数据渲染诊断卡片

---

## 📦 标准路径

### 第一步：定义输出 Schema

新建 `agent_structured.py`（基于 lab 05 的 `agent_langchain.py` 改造）：

```python
from pydantic import BaseModel, Field

class DiagnosisResult(BaseModel):
    """Agent 诊断结果——结构化 Schema"""
    severity: str = Field(description="严重程度：critical/ major/ minor/ normal")
    severity_reason: str = Field(description="严重程度判断依据，一句话")
    root_cause: str = Field(description="可能的根因分析")
    steps: list[str] = Field(description="推荐的排查步骤，按优先级排列，至少 3 条")
    escalate: bool = Field(description="是否需要升级为紧急工单")

# 创建 Parser
from langchain_core.output_parsers import PydanticOutputParser

parser = PydanticOutputParser(pydantic_object=DiagnosisResult)
```

### 第二步：改造 Agent 使用结构化输出

在 System Prompt 中注入 Parser 的格式说明：

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="deepseek-chat", temperature=0, ...)

prompt = ChatPromptTemplate.from_messages([
    ("system", """你是 5G 基站智能排障助手。根据设备数据给出诊断。

{format_instructions}

可用工具：{tools}
工具名称：{tool_names}"""),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])

# 把 format_instructions 注入 Prompt
prompt = prompt.partial(format_instructions=parser.get_format_instructions())
```

### 第三步：比对自由文本 vs 结构化输出

同一台告警设备，分别用 1.4（自由文本）和 1.5（结构化）跑：

| 对比维度 | 自由文本（1.4） | 结构化输出（1.5） |
|---------|-------------|----------------|
| 前端渲染 | 一整段文字，没法拆分 | 按卡片渲染：严重程度卡片、根因卡片、步骤列表 |
| 写入数据库 | 存文本 blob，没法查询 | 每个字段独立，可以查"本月 P0 告警有多少" |
| 下游消费 | 需要人读 | 程序可直接判断 escalate 字段决定是否创建工单 |
| 出错率 | Agent 可能忘记写某些部分 | Parser 强制所有字段必填 |

### 第四步：前端渲染结构化结果

收到结构化 JSON 后，前端不再是一段文字——渲染成诊断卡片：

```javascript
const data = JSON.parse(reply);  // reply 现在是 JSON

```

## 🏗️ 进阶挑战

### 对比两种 Parser

除了 `PydanticOutputParser`，LangChain 还提供了 `JsonOutputParser`（不需要 Pydantic，纯 dict）。对比两者：

- PydanticOutputParser：需要定义 Schema 类，类型安全，有自动验证
- JsonOutputParser：更轻量，适合快速迭代，没有类型检查

### 在前端加第三个按钮

设备详情页三个按钮并列：

```
[🤖 扣子/Dify] [🦜 LangChain] [📋 结构化诊断]
```

第三个按钮调 `/langchain/structured`，返回 JSON 并渲染为卡片。
