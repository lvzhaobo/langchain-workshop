### 创建 Chatflow

**1）新建应用**：
- 工作室 → 创建应用 → 类型选「Chatflow」
- 命名"5G基站RAG排障助手"

**2）编排管线**，从画布拖入三个节点并连线：

```
[开始] → [知识检索] → [LLM] → [结束]
```

**3）配置知识检索节点**：
- 知识库：选择刚创建的"5G基站排障知识库"
- 检索模式：混合检索（语义 + 关键词）
- TopK：3
- 相似度阈值：0.6

**4）配置 LLM 节点**：
- 模型：选 DeepSeek-Chat（或讲师指定）
- System Prompt：
  ```
  你是 5G 基站排障助手。根据知识库检索到的文档回答问题。

  要求：
  - 引用文档中的具体步骤和命令
  - 标注信息来源（文档名）
  - 如果知识库中没有相关内容，如实说明
  - 不要编造不存在的信息
  ```
- Context：选择「知识检索」节点的 `result`
- User Prompt：`{{sys.query}}`

**5）测试**：在右侧预览面板输入"AAU5613 退服了怎么一步步排查？"，观察：
- 回答是否引用了文档内容？
- 来源标注是否正确？
- 和 2.5 LangChain RAG 同一问题的回答有什么差异？

## 📦 接入平台

### 第一步：后端新增路由

在 `server.py` 中新增 Dify RAG 配置和路由：

```python
# Agent 配置区新增
DIFY_RAG_CONFIG = {
    "api_url": "改成你的 Dify RAG 应用 API 地址",
    "api_key": "改成你的 API Key",
}


@app.route("/dify-rag/analyze", methods=["POST"])
def dify_rag_analyze():
    """Dify RAG Agent 分析——发送设备故障信息到 Dify RAG 应用"""
    data = request.get_json()
    device_id = data.get("device_id", "").strip()

    # 找到设备数据
    device = None
    for d in devices:
        if d["device_id"] == device_id:
            device = d
            break
    if not device:
        return jsonify({"reply": f"设备 {device_id} 不存在"}), 404

    # 构造分析请求——带着设备上下文发给 Dify
    alarms = device.get("alarms", [])
    alarm_text = "\n".join([
        f"  - [{a['severity']}] {a['type']}: {a['description']}"
        for a in alarms
    ]) if alarms else "无告警"

    query = (
        f"设备 {device['device_id']}（{device['vendor']} {device['model']}，"
        f"站点 {device['site']}，状态 {device['status']}）出现以下告警：\n"
        f"{alarm_text}\n\n"
        f"请根据知识库给出诊断建议和排查步骤。"
    )

    try:
        resp = requests.post(
            DIFY_RAG_CONFIG["api_url"],
            headers={
                "Authorization": f"Bearer {DIFY_RAG_CONFIG['api_key']}",
                "Content-Type": "application/json",
            },
            json={
                "inputs": {},
                "query": query,
                "response_mode": "blocking",
                "user": "platform-user",
            },
            timeout=30,
        )
        data = resp.json()
        reply = data.get("answer", "Dify 未返回内容")
        return jsonify({"reply": reply})
    except requests.exceptions.Timeout:
        return jsonify({"reply": "Dify RAG 响应超时"})
    except Exception as e:
        return jsonify({"reply": f"Dify RAG 调用失败：{str(e)}"})
```

## 📊 Dify RAG vs LangChain RAG 对比

同一台告警设备，分别点「📚 RAG 分析」（lab 14）和「🔷 Dify RAG」（lab 15）：

| 维度 | LangChain RAG（lab 14） | Dify RAG（lab 15） |
|------|-------------------|----------------|
| 搭建方式 | 写 Python 代码 | 网页拖拉拽 |
| 知识库 | FAISS 本地索引 | Dify 内置向量引擎 |
| 检索配置 | 代码控制 TopK/阈值 | UI 表单配置 |
| 工作流 | Agent 自主决定调哪个工具 | 固定管线：检索 → LLM |
| 灵活性 | 无限——可自定义任何逻辑 | 受限于 Dify 平台能力 |
| 调试 | IDE 断点 + verbose 日志 | Dify 预览面板 |
| 适合谁 | 开发岗 | 全员 |
